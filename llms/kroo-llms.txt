# Kroo

> Kroo Bank Ltd is a UK app-based challenger bank (founded 2016, full PRA/FCA banking licence 2021) offering a fee-free digital current account. As an FCA-authorised ASPSP under PSD2, Kroo exposes the UK Open Banking Implementation Entity (OBIE) Read/Write API family — Account & Transaction Information, Payment Initiation, and Confirmation of Funds — through a Banfico-hosted developer portal, secured with FAPI-grade OAuth2/OIDC, PSD2 SCA (CIBA decoupled flow), and mutual-TLS with OBIE/eIDAS certificates. Access requires third-party-provider (TPP) onboarding; there is no anonymous public API.

## APIs

- [Kroo Account and Transaction Information API](https://developer.kroo.banfico.io/): PSD2 AIS dedicated interface (OBIE Read/Write v4.0.1) — accounts, balances, transactions, beneficiaries, standing orders, direct debits, scheduled payments, statements.
- [Kroo Payment Initiation API](https://developer.kroo.banfico.io/): PSD2 PIS dedicated interface (OBIE Read/Write v4.0.1) — domestic payments, scheduled payments, standing orders, file payments.
- [Kroo Confirmation of Funds API](https://developer.kroo.banfico.io/): PSD2 CBPII dedicated interface (OBIE Read/Write v4.0.1) — confirm funds availability without disclosing balance.
